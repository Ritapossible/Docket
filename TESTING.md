# Testing

Six layers, each catching something the one below it cannot. Run all of them with the commands
in `CONTRIBUTING.md`; CI runs all of them on every push.

## 1. Contract unit tests - `make test`

32 tests in `contracts/test/`. Test names carry the threat-model row they cover (`_T3_`), and
`script/check-threat-coverage.sh` fails the build if `spec/THREAT-MODEL.md` claims a row is
covered and no test names it. That check has already caught one claim that was not true.

The most important single test is `testFuzz_I2_policyViolationNeverReverts`, which asserts over
256 runs that no policy violation can revert. A revert would destroy the `Denied` record the
whole product rests on.

## 2. Gas and size - `make gas`, `forge build --sizes`

`contracts/test/Gas.t.sol` measures cost against tracked-asset count and the worst-case window
eviction, with budgets set from measurements rather than from round numbers. `--sizes` exits
non-zero over EIP-170, which was added after a contract shipped 641 bytes over the limit and
would have deployed fine in tests and reverted on a real chain.

## 3. DCS-1 conformance - `npm run test:dcs1`

15 vectors in `indexer/test/`, **hand-computed from `spec/DCS-1.md`** rather than captured from
the implementation. A golden file generated by the code under test proves only that the code
agrees with itself; these make the spec the authority.

## 4. End-to-end beat - `make demo`

Boots a chain, deploys a mandate, runs the injection scenario, and asserts the refusal holds and
reaches the score. It found a bug no unit test could: viem caches the head block number, so a
replay moments after a denial landed scored a stale chain and reported 331 when the truth was
218. Every unit test constructs its own history, so none of them could have seen it.

## 5. Console render - `make console-e2e`

Serves the built console against a seeded chain and fails if the page loads but shows nothing.
A build that compiles proves nothing about a dashboard.

## 6. Responsive - `console/scripts/check-responsive.mjs`

Asserts no horizontal overflow at 320, 360, 390, 430, 768, 1024 and 1280. Overflow gets its own
test because it is invisible on a desktop and ruins the page on a phone, and the causes look
innocuous: a `white-space: nowrap`, a `flex-basis`, a `min-width` set inline.

## Production headers

`node console/scripts/serve-static.mjs` serves the build with the exact header set parsed out of
`vercel.json`, so the Content-Security-Policy can be tested before it ships. A CSP that blocks
the app's own bundle is indistinguishable from a broken deploy.

## Not yet covered

Listed so the gaps are known rather than assumed. See `ARCHITECTURE.md` §10.

- **Stateful invariant tests.** Unit tests assert scenarios; a contract whose job is holding a
  bound under adversarial sequencing needs properties that survive arbitrary orderings.
- **Static analysis.** No Slither or Aderyn run.
- **Coverage floor.** `forge coverage` is not measured or gated.
- **Live-chain latency.** The act-to-finality measurement the Monad argument depends on.
